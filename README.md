# ShopZone — Amazon-Style E-Commerce Store

My first front-end web development project built with **HTML**, **CSS**, and **JavaScript**, and deployed live using **GitHub Pages**.

## Features
- Amazon-inspired navigation bar and product cards
- Real-time product search bar
- Category filter buttons (*All*, *Audio*, *Wearables*, *Accessories*)
- Interactive slide-out shopping cart drawer with add, remove, and live total calculation
